# Project Statement

## Title
**Quiz Application using Tkinter**

## Objective
To develop a desktop-based quiz application with a graphical user interface where a user can select a quiz category and difficulty, answer multiple-choice questions, work against a timer, and receive a score at the end.

## Problem Statement
Traditional text-based quizzes are simple but do not provide an engaging graphical experience. This project solves that problem by creating an interactive quiz application using Python Tkinter. The application displays questions and options in a GUI, tracks answers, applies a time limit, and calculates the final result.

## Main Concepts Used
- Python functions
- Lists and dictionaries
- JSON file handling
- Conditional statements
- Loops
- Exception handling
- Random question selection
- Tkinter widgets
- Tkinter event scheduling with `after()`
- Basic software testing

## Expected Outcome
A user-friendly desktop quiz application that runs locally and provides immediate score statistics after the quiz is completed.
